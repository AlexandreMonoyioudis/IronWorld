# IronWorld

**Prerelease - version 0.1**

IronWorld is a Mindustry mod featuring an iron-rich moon orbiting Serpulo. Capture it and establish a foothold across its sectors.

## What it includes

- The custom IronWorld planet
- Three sectors: Impact Crater, Iron Mounds and Choke Hold

## Requirements

- Mindustry build 147 or later

## Prerelease notice

IronWorld is still in prerelease. Features, balance, maps, and compatibility may change, and bugs are expected. Please give me feedback, it is useful to improve the mod.

For feedback or bug reports, open an issue in the [GitHub repository](https://github.com/AlexandreMonoyioudis/IronWorld/issues).
